# IDOL LIFE — 게임 기획 기준서 (2026-11-18)

상태: **기획 기준**. 현재 코드와 일치하지 않는 부분은 구현 과제이며 반영 완료로 간주하지 않는다.

## 게임 정체성
- 장르: 선택과 확률에 따라 다른 인생이 펼쳐지는 K-pop 커리어 시뮬레이션.
- 플레이어는 평범한 학생으로 시작하여 우연한 기회 또는 적극적인 도전으로 산업에 진입할 수 있다.
- 성공은 단선형 엔딩이 아니다: 데뷔 실패, 무명 생활, 늦은 역주행, 그룹·솔로 활동, 배우·제작자 전향, 해체·재결합, 은퇴 등이 존재한다.
- 게임의 중심은 학교 전체 인생이 아니라 **아이돌 산업으로 이어질 수 있는 짧은 학생 프롤로그와 커리어**이다. 연예계 밖 삶은 짧은 에필로그로 처리한다.
- 외형 아바타는 MVP 필수 요소가 아니며 텍스트·기록·관계·시간의 흐름이 핵심이다.

## 캐릭터 생성
- 이름: 직접 입력 또는 랜덤 생성. 예명은 추후 별도 구현 가능.
- 성별: 남성/여성/랜덤(랜덤 기본값 제안; 구현 시 선택 UI 검토).
- 시작 나이: 13~18세 무작위.
- 외모·능력치·가정환경: 무작위이며 모두 좋은 결과만 만드는 능력치 조합을 피한다.
- 기본 능력 후보: 보컬, 댄스, 랩, 연기, 스타성, 멘탈, 체력. 성별로 타고난 실력 보너스를 부여하지 않는다.
- 아이돌 희망 정도 또한 캐릭터별로 다르다. 관심이 없어도 우연한 기회가 찾아올 수 있다.

## 확정된 핵심 루프
1. 게임 속 시간이 실시간으로 자동 흐른다.
2. 학교·훈련·계약·그룹·음악·팬덤·사생활 등 일반 소식이 시간순으로 축적된다.
3. 평소 활동 방침은 자동 성장·피로·일정·관계에 영향을 준다. 언제든 일시정지·변경할 수 있다.
4. 중요한 결정(진입·계약·데뷔·활동·건강·분쟁·전향·은퇴)일 때 자동으로 멈춘다.
5. 선택의 즉시 결과와 지연 결과는 현재 상태와 기록에 반영된다. 별도의 결과 확인 버튼은 없다.
6. 커리어 종료 시 단일 점수가 아닌 최전성기·작품·수입·관계·전환점·에필로그로 회고한다.

## 시간 설계: 합의안과 실제 코드 차이
- 사용자와 합의한 **테스트 목표값**: ×1 기준 1년 = 실제 60초(1개월≈5초), ×1/×2/×4/×8, 매일 계산, 중요 결정 시 자동 정지.
- 플레이타임: 목표 30~40분이지만 은퇴·전향·실패에 따른 차이를 허용한다. 전체 플레이타임을 인위적으로 고정하지 않는다.
- 소식 노출 빈도는 실제 계산/세계 시간과 별도 관리한다. 5초에 한 달이 지나가는 경우 소식 홍수를 막기 위해 중요 소식을 강조하고 사소한 변화는 요약한다.
- **2026-11-18 저장소 확인 결과** js/config.js의 dayMs는 240000/365로, 현재 ×1에서 1년 약 240초다. 합의한 시험 속도(60초)와 다르다. 단순 숫자 변경 전에 읽기 밀도·체감 테스트를 수행해 조정한다.
- 중요한 결정을 건너뛰는 스킵은 모든 중간 날짜를 계산하고 중요한 결정에서 멈춰야 한다.
- 자동 결정 모드 및 배속 상향은 장기적으로 고려하되 실시간 경험과 엔진 일관성이 우선이다.

## 커리어 상태
- 현재 실제 코드에서 확인된 단계: student → auditioning → trainee → debut_candidate → idol 또는 solo → actor/producer 전향 → ended.
- 정규 연습생 외 서바이벌 프로그램의 후보 직행과 재도전이 가능해야 한다.
- 상세한 rookie/veteran/hiatus 등은 콘텐츠 데이터의 분류 후보이며 현재 코드 단계로 바로 간주하지 않는다.
- 그룹 탈퇴와 연예계 은퇴는 구분한다. 은퇴는 사건 맥락과 자발적 선택에 기반하도록 설계한다.

## 플레이어 선택권의 현실성
- 학생: 취미, 오디션, 공연/SNS 참여, 캐스팅 검증과 수락 여부.
- 연습생: 훈련 방침, 인간관계, 계약 대응, 평가 준비.
- 신인: 회사가 정한 콘셉트를 전달받은 뒤 보컬/댄스/캐릭터 표현 등에 집중; 활동 일정·제안 대응.
- 인기 아이돌: 부분적 창작 참여, 예능·광고·개인 활동, 활동 노선, 계약·휴식 협의.
- 베테랑: 재계약, 독립, 제작·연기·솔로, 그룹 지속/해체/재결합.

## 사용자 피드백에 따른 핵심 수정
- 시작하자마자 첫 무대로 향하는 문/연습생 친구 저녁 소식: 부자연스럽다. 학생 일상부터 시작.
- 모든 소식에 선택→결과→다음 버튼: 재미없다. 자동 시간과 관찰 중심.
- 새 연습생과 친해진 뒤 밥 먹는 소식만 있는 결과: 불충분하다. 관계가 훈련·평가·미래 선택에 연결되어야 한다.
- 몇 개의 일상 문장이 반복: 중복 필터, 커리어 단계별 풀, 인과관계/상태 기반 소식 필요.
- 데뷔 성공을 한 줄로 처리: 전용 성취 연출이 필요.
- 매번 비슷한 진로 변경/은퇴 결정: 실제 전환 계기가 있을 때만 발생.

## 완료 판정
플레이어가 아무 행동을 하지 않아도 새로운 소식이 쌓이고, 전후 관계가 이어지며, 중요한 순간에 주목하고 개입하고 싶어지는가? 이 체감이 최우선 QA이다.

## 2026-11-18 확정한 게임 분위기
- **현실적인 일상과 인간관계를 기본으로 하되, 가끔 예상하지 못한 드라마틱한 전환점이 일어나는 균형형**을 기준으로 한다.
- 극적인 사건은 무조건 선정적인 위기일 필요가 없다. 뜻밖의 성공, 탈락, 발탁, 팀 상황 변화도 포함한다.
- 모든 큰 사건은 실제 인물·회사·활동·게시/공연 등 앞선 원인에서 발생해야 한다. 사건 후에는 관계·커리어·세계 상태에 장기적 변화를 남긴다.
- 실시간 자동 소식이 중심이고 모든 일상에 중요한 결정 팝업을 붙이지 않는다.
- 최초 소속사 계약부터 데뷔 후 6개월까지의 상세 스토리/사건/상태 기획은 [ACT 1 설계서](ACT1_STORY_DESIGN.md)를 참고한다. **현재 기획 제안이며 구현 완료 아님.**
