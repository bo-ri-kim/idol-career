## 실제 화면과 엔진 동작

제안 카드에 실제 회사명·규모·성향·운영·보유 자원·훈련 장점·기대 역량·현재 능력·합동 연습 경험·프로젝트 현황·확인된 조건·미확인 사항을 표시한다. 현재 제안 전 등록 프로젝트가 없으면 ‘없음’, 선발/데뷔 일정·계약 종료일·교육/숙소비 분담·수익 배분은 ‘미확인’이라고 보여 준다. 아직 존재하지 않는 데뷔 팀이나 확정 일정은 만들지 않았다.

플레이어는 집중 교육/빠른 데뷔/창작 참여/안정적 지원 중 중시할 조건을 고를 수 있다. 선호와 회사 교육 강점·경쟁 부담·자원·현재 능력을 비교해 장점과 부족한 근거를 함께 설명한다. 팀워크 평가는 합동 연습 경험과 구분하고, 창작 교육이 곧 최종 콘셉트 결정권이라고 표현하지 않는다. 적합성 문구는 합격 보장이나 숨겨진 성공 보너스가 아니다.

- **조건 확인**: 보호자/신뢰할 수 있는 동반자와 7일간 검토. 아직 무소속이며 계약은 자동 체결되지 않는다. 완료 사건 ID가 있어야 수락 가능하다. 모든 신규 계약에 적용하는 게임 내 검토 절차이며 실제 법률상 연령·계약 요건을 확정한 것이 아니다.
- **보류**: 한 번, 7일 경과 후 같은 제안을 다시 연다. 유효기간도 7일 연장한다. 상담 완료로 간주하지 않는다.
- **수락**: 합격·현재 제안·회사 정보·상담 완료 사건을 다시 검사한다. 실제 계약과 현재 소속이 같은 회사로 연결된다.
- **거절/만료**: 계약 없이 학생으로 돌아가며 다른 기회가 이어진다. 옛 제안은 보존한다.
- **나중에 결정하기**: 기존 기능대로 팝업만 내려두고 시간을 멈춘다. ‘7일 보류’와 동작을 구분한다.

### 실제 플레이 예시

계약 전: ‘새벽 엔터테인먼트 · 소형 · 창작’, 자원 40/100, 보컬·랩 밀착 지도. 현재 보컬 23/100·랩 18/100은 보완 필요, 회사 팀워크 평가는 미확인. ‘창작 참여’를 고르면 랩·창작 피드백 강점과 최종 결정권 미확인을 함께 설명한다. 상담 전 수락 버튼은 비활성이다.

실플레이에서 2027.06.09 제안 → 7일 보류 → 06.16 동일 회사 재검토 → 상담 → 06.23 상담 완료 후 계약. 계약 후 현재 소속도 새벽 엔터테인먼트이고 자원 39, 실제 프로젝트 1기가 생성됐다. 재로드 후에도 같은 회사·선호·상담 완료 상태가 복원됐다. 해당 게임 URL의 콘솔 오류는 없었다.

## 회사가 실제로 바꾸는 두 계산

회사 규모에 일괄 성공 보너스를 주지 않았다. 기존 3개 회사와 프로그램의 프로필만 사용한다.

| 회사 | 강화 훈련 예시 | 월말 경쟁 동료 성장 배수 |
| --- | --- | ---: |
| orbit | 댄스 1.35, 보컬 1.05 | 1.30 |
| dawn | 보컬 1.15, 랩 1.35 | 0.75 |
| onair | 연기 1.35, 스타성 1.30 | 1.00 |
| program | 댄스 1.15, 스타성 1.25 | 1.45 |

다른 분야는 기본보다 낮은 배수도 있어 모든 회사가 모든 방면에서 좋지는 않다. 회사별 배수는 준비 단계의 실제 일별 훈련 성장에만 적용하고 휴식/학생/데뷔 후 성장은 바꾸지 않는다. 월말 경쟁 점수 변화는 기존 후보 선발·데뷔 확률에 그대로 사용된다. 이 값은 게임 밸런스이며 업계 통계가 아니다.

같은 캐릭터·난수·균형 훈련·31일을 비교한 실제 계산:

| 회사 | 댄스 증가 | 랩 증가 | 경쟁 동료 평균 평가 변화 |
| --- | ---: | ---: | ---: |
| orbit | 1.375 | 0.606 | 0.415 |
| dawn | 0.917 | 0.962 | 0.239 |

이는 비교를 위해 회사만 일관되게 바꾼 테스트다. 현재 UI에 복수 회사 동시 선택 기능이 있다는 뜻은 아니다.

- 새 저장: 같은 제안/회사/상담 예약/선호를 복원한다. 회사·합격·상담 참조가 끊기면 읽기를 거부하며 원본을 지우지 않는다.
- 이전의 대기 계약: 실제 합격 기록을 확인하고 회사가 있는 제안을 복원한다. 아직 계약 전인 제안만 새로 확정하고 안내한다. 상담을 생략해 수락하지 않는다.
- 이전의 이미 체결된 계약: 기존 회사와 계약 ID를 그대로 두고 legacyAgencyContract로 표시한다. 존재하지 않았던 과거 제안/상담을 만들어 넣지 않는다.
- 합격 이력을 확인할 수 없는 옛 대기 제안은 정확한 사유와 원본 보존 메시지를 반환한다. 자동 저장 초기화는 하지 않는다.
