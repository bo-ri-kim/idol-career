# K-pop 산업 조사 메모 — 게임화 근거

목적: 실제 업계의 **작동 원리**를 게임 시스템에 반영한다. 사건의 극적 사례가 흔하다는 뜻은 아니며, 인터뷰·언론 보도·개별 사례는 업계 전체의 규칙으로 일반화하지 않는다.

## 핵심 관찰 및 설계 해석
| 현실에서 참고할 구조 | 게임에 대응 |
| --- | --- |
| 오디션·스카우트·SNS·공연 등 진입 다양성 | 학생→다양한 접촉과 심사, 회사 제안 |
| 연습생의 평가·피로·불확실성·동료 지원 | 경쟁과 관계, 교육 자원, 상태·멘탈 |
| 기획사 규모와 프로젝트 자원의 차이 | 회사별 자금·교육·홍보·운영 성향 |
| 그룹과 개인의 인기도 차이 | 그룹/개인 인기도 별도 추적 |
| 음원/음반/대중성/팬덤/정산의 차이 | 다차원 성과 및 수익 모델 |
| 짧은 직캠·SNS 바이럴로 과거 곡이 재발견 | 오래된 발매곡의 조건부 역주행 |
| 연습·방송·투어·이동으로 누적되는 피로 | 일정·건강·안전/회복 |
| 그룹 안의 파트·리더십·협업 문제 | 포지션, 소속 인물 관계, 갈등 |
| 재계약·병역·이적·솔로/연기 전향 | 후기 커리어 분기 |
| 미성년자 보호와 계약 규정 | 연령·국적·자격·보호자 관련 상태 |

## 참고할 공개 사례
- EXID 2014년 '위아래' 직캠 확산 후 역주행: 한 사람의 영상이 그룹 커리어에 줄 수 있는 지연 효과. 관련 사실은 보도/공식 자료로 검증 후 텍스트화.
- 브레이브걸스 2021년 'Rollin’' 재유행: 활동 공백·종료 위기와 늦은 성공의 대비. 동일 재현이 아니라 일반적인 역주행 기제만 추출.
- 장기 그룹 활동·재계약: 개인의 커리어 계획과 팀 유지가 충돌/조율되는 구조.
- 공개 오디션 및 기획사 자료: 지원/선발/진입 경로의 현실적 형식.
- 정부 표준계약서 및 청소년 대중문화예술인 보호 자료: 계약 유형, 나이, 활동 제약.
- 차트 공식 집계: 음원과 음반의 구별.

## 안전·품질 원칙
- 실존 연예인의 사생활 또는 확인되지 않은 갈등을 허구 사건의 사실 근거로 쓰지 않는다.
- 건강 문제, 사고, 범죄·괴롭힘의 책임을 피해자의 '잘못된 선택'으로 돌리지 않는다.
- 피해 및 갈등은 대응, 회복, 보호, 합의, 구조적 제약의 선택지로 다룬다.
- 민감한 사건은 드물고 맥락에 맞게 발생하도록 하며 자극을 위해 남발하지 않는다.
- 계약·병역·미성년자 보호는 현재 법률을 사실처럼 임의 단정하지 않는다. 코드를 만들 때 별도 최신 검증이 필요하다.
