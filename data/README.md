# 콘텐츠 팩 적용 안내

별도 제작된 v0.3 콘텐츠 팩은 아래 네 묶음이다.
- 일반 소식 300개
- 선택 이벤트 30개
- 연속 사건 19개 / 76단계
- 실제 계산값 기반 템플릿 34개

이 팩은 JSON 형태의 **게임용 데이터**이지 바로 실행되는 시뮬레이션 엔진이 아니다.
현재 저장소는 student/auditioning/trainee/debut_candidate/idol/solo/actor/producer/ended 단계 등을 사용하며, 콘텐츠 팩은 일부 다른 단계 이름과 조건 필드를 갖는다.

파일이 저장소에 추가되면 다음 순서로 적용한다.
1. 기존 상태/조건 엔진 매핑과 후보 데이터의 무결성 검사
2. 학생/연습생/아이돌 일반 소식의 상태별 중복 방지
3. 실데이터가 있는 상태 기반 소식 연결
4. 인물·곡·소속사 ID를 유지하는 연속 사건 연결
5. 결정 효과가 실제 계산에 반영되는지 테스트

콘텐츠를 로드할 수 없을 때 임의로 가짜 수치를 채워서 소식을 노출하지 않는다.
이 파일은 소식 라이브러리의 존재·구현 여부를 대신 증명하지 않는다.
