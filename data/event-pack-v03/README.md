# IDOL LIFE 콘텐츠 팩 v0.3 — 데이터 구조

이 폴더는 ChatGPT에서 설계·작성한 게임용 **원본 후보 콘텐츠**를 담는다. 현재 게임에 자동 적용된 상태가 **아니다**.

## 파일 목록
| 파일 | 유형 | 수 |
| --- | --- | ---: |
| ambient_student.json | 학생 생활 및 학생 단계 사용 일반 소식 | 66 |
| ambient_trainee.json | 연습생·데뷔 후보 등 일반 소식 | 78 |
| ambient_debut.json | 데뷔 후, 전향 등 일반 소식 | 156 |
| decisions.json | 중요 선택 이벤트 | 30 |
| arcs.json | 연속 시나리오 | 19개(총 76단계) |
| derived.json | 실제 상태 수치 기반 소식 | 34 |
| manifest.json | 콘텐츠 규칙·단계명·통합 가이드 | 1 |

총 300 일반 소식 + 30 중요 선택 + 76 시나리오 단계 + 34 상태 기반 템플릿 = **440개 콘텐츠 단위**.

## 주의 사항
- 저장소의 단계명 및 변수는 원본 후보 JSON의 `phase_ids`, `suggested_state_paths`와 **다를 수 있음**.
- 이는 특정 문구가 나올 수 있는 조건을 설명한 초기 데이터이지 실제 발생 확률·사건 순서의 구현을 보장하지 않음.
- 실제로 없는 회사·곡·그룹·계약·인물·음원 지표를 지어내서는 안 됨.
- 일반 소식은 커리어당 1회 및 카테고리 쿨다운으로 반복을 억제.
- 작은 소식의 자동 발생은 시간을 멈추지 않음.
- 결정 이벤트의 효과는 실제 능력·관계·커리어 계산에 연결되어야 함.
- 아크는 인물/곡/회사 ID, 선행 사건, 실제 상황 및 예약 일정을 유지.
- 실제 적용 범위는 docs/IMPLEMENTATION_PLAN.md 의 NEXT 및 docs/EVENT_DESIGN.md를 따른다.

## Codex 첫 적용 권장
1. 현재 상태와 타입을 분석하여 데이터 매핑 표를 만든다.
2. 학생·연습생·아이돌 단계에 맞는 ambient 후보를 선정하여 조건 엔진에 연결한다.
3. 중복 방지 및 QA를 먼저 검증한다.
4. 이후 실제 계산값 기반 소식과 연속 사건을 점진적으로 활성화한다.
5. 테스트를 마친 실제 연결 건수와 미구현 이벤트 건수를 분명히 보고한다.
