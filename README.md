# 다음 무대 — 아이돌 커리어 MVP v0.1

한국어 텍스트 기반 모바일 웹게임. HTML, CSS, Vanilla JavaScript만 사용하며 외부 이미지, API, 유료 서비스, 백엔드, 설치 의존성이 없습니다. 모든 진행과 저장은 브라우저 안에서 이뤄집니다.

## 실행

이 폴더에서 다음 명령을 실행하세요.

```sh
python3 -m http.server 8080
```

브라우저에서 http://localhost:8080 을 엽니다. Node가 있다면 `npm start`도 같습니다. ES 모듈을 사용하므로 index.html을 직접 더블클릭하는 file:// 실행 대신 로컬 정적 서버가 필요합니다. 이 서버는 파일만 제공하며 게임 로직이나 사용자 데이터를 처리하지 않습니다.

모바일 기기에서 실행하려면 같은 Wi-Fi에 연결하고 `http://컴퓨터의로컬IP:8080`을 엽니다. 모바일의 localhost는 컴퓨터를 가리키지 않습니다. 저장은 기기·브라우저·주소별로 독립적이며 서로 동기화되지 않습니다.

## 파일 구조

- `index.html`: 진입 문서
- `styles.css`: 다크 테마, 모바일 우선 반응형 UI, 최소 48px 버튼
- `js/state.js`: 단일 상태 객체 생성, 능력치/단계 정의, localStorage 저장
- `js/random.js`: 범위 제한, 정수 추첨, 확률 판정, 시드 난수
- `js/events.js`: 30개 이벤트 템플릿과 별도 기본 이벤트. 단계 조건, 선택, 확률 계수, 성공/실패 문구와 변화량을 데이터로 정의
- `js/engine.js`: 사건 선택, 확률 계산, 시간 경과, 상태 전환, 업적, 종료 규칙
- `js/app.js`: 시작·진행·결과·히스토리·결산 화면과 입력 처리
- `tests/engine.test.js`: 경로 및 반복 시뮬레이션 테스트

## 플레이 규칙

- 이름 직접 입력 또는 랜덤 생성. 성별 랜덤/남성/여성, 시작 나이 13~18세. 성별은 실력 추첨과 확률에 영향을 주지 않습니다.
- 보컬·댄스·랩·연기·스타성·멘탈·체력은 0~100. 외모와 가정환경도 랜덤입니다. v0.1에서 외모는 프로필 정보이며, 가정환경은 준비 기간의 생활비에 영향을 줍니다.
- 한 번의 선택은 3개월. 생활비/활동 수입도 함께 정산합니다. 자산 단위는 만원이며 부채 하한은 -500만원입니다.
- 오디션·캐스팅·SNS → 연습생 → 정기 데뷔 평가 → 그룹 또는 솔로 활동. 실패하면 준비 기간을 거쳐 재평가할 수 있습니다.
- 실력, 누적 연습 기간과 창작 경력이 확률에 반영됩니다. 이전 선택으로 변화한 실력이 이후 성공 가능성을 바꿉니다. 확률은 5~95%로 제한되어 성공이 보장되지 않습니다.
- 그룹/솔로에서 배우·제작자로 옮기면 아이돌 은퇴로 기록하고 연예계 커리어는 계속됩니다. 연예계 은퇴는 결산으로 이어집니다.
- 일반 사건은 최근 5턴 안에 반복되지 않습니다. 핵심 진입·훈련·데뷔·진로 선택은 재사용 가능합니다. 사건 풀이 부족하면 기본 일상 사건으로 진행됩니다.
- 진입이 오래 지연되면 23세 또는 24턴에 배우로 새 출발합니다. 연습생/데뷔 단계는 27세 또는 5회 실패 시 배우로 전향합니다.
- 45세, 128턴, 체력/멘탈 0 또는 자발적 은퇴 시 종료합니다. 회복 선택으로 건강을 관리할 수 있습니다.
- 선택하지 않은 기회는 다음 사건으로 갱신되며, 3개월의 생활과 수입은 자동 정산됩니다. 앱을 닫아둔 실제 시간에는 진행되지 않습니다.
- 선택 직후 및 다음 사건 진입 시 자동 저장합니다. 시작 화면에서 이어하기·새 게임·저장 초기화를 제공합니다. 저장은 한 슬롯이며 새 게임 덮어쓰기와 초기화에는 확인창이 있습니다.

## 검증

```sh
npm test
```

Node 내장 테스트만 사용합니다. 글로벌 스타, 데뷔 실패 후 배우/제작자 전향, 아이돌 은퇴와 자발적 연예계 은퇴, 200개 시드의 완결 생애, 30개 이벤트 ID와 선택 개수, 확률 재현성을 검증합니다.

자동 검증 결과: 5개 테스트 통과. 각 생애가 128턴 이내에 종료되고 모든 능력치가 범위 안에 있는지 확인했습니다. JS 문법 검사와 HTTP 파일 제공도 확인했습니다.

현재 채팅의 브라우저 접근이 비활성화되어 실제 콘솔 오류와 360px 렌더링은 직접 검증하지 못했습니다. 아래는 남은 수동 점검 항목입니다.

1. 개발자 도구에서 화면 폭 360px로 설정하고 새 게임, 긴 이름, 모든 선택 버튼, 히스토리와 결산 화면의 가로 넘침 확인.
2. 콘솔을 연 채 생성 → 선택 → 결과 → 다음 사건 → 새로고침 → 이어하기 확인.
3. 연예계 은퇴 후 결산과 재접속 확인. 저장 초기화 취소/확인 확인.

## 현재 한계

v0.1의 수입·계약·인기도는 단순화한 가상 수치입니다. 소속사/멤버별 시뮬레이션, 실제 음원 차트, 관계 시스템, 세부 재무·투자, 저장 내보내기, 여러 저장 슬롯은 없습니다. 30개 사건을 재사용하므로 긴 플레이에서는 문구가 반복됩니다. 향후 더 다양한 개인 서사와 분기 에필로그, 플레이 밸런싱이 필요합니다.
