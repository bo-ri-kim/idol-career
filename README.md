# 다음 무대 — IDOL LIFE v0.2.9

평범한 학생으로 시작해 일상과 우연한 계기를 거쳐 아이돌 산업에 진입하는 데스크톱 웹 인생 시뮬레이션입니다. HTML·CSS·Vanilla JavaScript만 사용하며 외부 API, 백엔드, 유료 서비스, 외부 이미지가 없습니다.

플레이: https://bo-ri-kim.github.io/idol-career/

## 실행

프로젝트 폴더에서 실행하고 http://localhost:8080 을 엽니다.

```sh
npm start
# 또는
python3 -m http.server 8080
```

ES 모듈이므로 file:// 더블클릭 대신 정적 서버가 필요합니다. 서버는 파일만 제공하며 모든 게임 계산과 저장은 브라우저에서 실행됩니다. 공개 GitHub Pages 주소는 컴퓨터가 꺼져 있어도 접속할 수 있습니다.

## v0.2.9: ACT 1 / 01 소속사 계약 제안·적합성

심사 합격 때 실제 회사가 정해진 제안을 만들고, 수락 전에 회사명·규모·성향·자원·교육 강점·기대 역량·프로젝트·미확인 조건을 보여 줍니다. 집중 교육/빠른 데뷔/창작 참여/안정적 지원 중 선호에 따라 맞는 점과 불확실성을 비교합니다.

보호자/동반자와 7일간 조건을 확인한 뒤 수락할 수 있고, 7일 보류나 거절도 가능합니다. 수락 후 회사는 다시 추첨하지 않습니다. 회사별 교육과 경쟁 성향은 실제 훈련 성장·동료 평가에 반영합니다. 기존 저장의 회사와 경력은 유지하고, 옛 회사 미정 제안은 안내와 함께 복원합니다.

`npm test` 72개 통과, `npm run qa:agency` 100개 시드에서 회사 불일치/상태 오류 0. [계약 전후 UI·인과관계·테스트·미구현 보고](docs/ACT1_01_IMPLEMENTATION_REPORT.md), [QA 수치](docs/agency-qa-v029.json). 이번 NEXT 하나만 구현했으며 숙소 아크·데뷔 연출·발매 시스템 등은 대기열입니다.

## v0.2.8: 결정 팝업을 내려두고 소식 읽기

## v0.2.7: 학생 활동과 기회의 원인 연결 (P0-1~3)

가족 동거/숙소/독립 거주를 구분해 집에 사는 학생·연습생에게 ‘집에서 온 연락’이 나오지 않도록 했습니다. SNS 친숙도는 게시나 노출이 아닙니다. 실제 공개 영상과 해당 영상의 노출 기록이 있어야 SNS 심사 제안 후보가 됩니다.

31일째 방과 후 활동을 선택합니다. **댄스 → 교내 공연**, **음악 → 지도자 동반 거리 공연**, **영상 → 공개 여부 선택·게시·노출**의 3개 체인이 있습니다. 가입하지 않거나 공개하지 않으면 관련 발탁은 발생하지 않습니다. 실제 공연/게시·선행 연습의 사건 ID가 심사 제안에 연결되며, 공개했어도 연락과 합격은 보장되지 않습니다.

기존 저장은 이어갈 수 있습니다. 과거 경력을 되돌리거나 게시물을 만들어 넣지 않습니다. 무소속 상태에서 근거 없이 대기 중인 옛 SNS/공연 제안만 보류하고 안내합니다.

`npm test` 61개 통과. `npm run qa:student`로 첫해 400개 및 7년 100개 플레이를 확인했고, 대상 원인 조건 위반은 0입니다. [문제별 수정·미해결 보고](docs/PLAYTEST_FIX_REPORT_2026-11-18.md), [QA 원본](docs/student-qa-v027.json)을 참고하세요. 데뷔 축하·갈등·콘셉트 권한·발매 모델·솔로/배우 확장은 이후 NEXT로 남아 있습니다.

## v0.2.5: 관계가 실제 플레이에 이어지도록 보강

첫 재회 이후에도 같은 인물과 대략 65일 간격으로 중요한 관계 결정이 찾아옵니다. 일상 소식은 계속 자동으로 흘러갑니다.

- 합동 준비: 체력과 연습 시간을 쓰고 신뢰를 높입니다. 14일 뒤 관계·실력에 따른 합동 평가 결과가 나옵니다. 성공하면 동료의 실력도 함께 오릅니다.
- 단독 파트: 스타성을 얻지만 신뢰가 낮아지고 경쟁이 깊어집니다. 성공하면 큰 개인 성과를 얻고, 실패하면 기회를 놓칩니다.
- 경계 조율: 추가 평가 기회를 포기하고 멘탈과 관계의 선을 회복합니다.
- 평가 성과는 프로젝트 관계 점수로 누적되어 후보 선발과 최종 데뷔 확률에 반영됩니다. 소속 패널과 결과 소식에서 실제 수치를 보여 줍니다.
- 같은 그룹으로 데뷔하면 합동 무대·파트 경쟁과 인기 변화로 이어집니다. 서로 다른 데뷔 명단이면 이를 기록하고 함께하는 활동은 중단됩니다.
- v0.2.4 저장을 그대로 이어갈 수 있습니다. 이미 첫 만남을 마친 인물도 새 만남 없이 후속 일정이 연결됩니다.

브라우저에서 기존 저장 이어하기 → 지후의 합동 제안 → 14일 뒤 프로젝트 평가 +4점 → 재등장 → 단독 파트 선택 → 파트 갈등으로 내용 변경을 확인했습니다. 게임 소스 오류는 관찰되지 않았습니다.

## 지속적인 세계와 인물관계 (v0.2.4)

기존 단일 상태 객체에 `world` 레지스트리를 추가했습니다. 소속사·등장인물·그룹·프로젝트·계약은 고유 ID로 연결하며, 현재 소속과 과거 활동 기록을 분리합니다. 기존 실시간 엔진·배속·최신순 타임라인·결정 팝업을 유지합니다.

- 연습생 계약 이후 실제 인물 3명이 경쟁자로 생성되고, 새 연습생 한 명이 합류합니다.
- 첫 만남에서 친해지기·견제하기·거리 두기를 선택합니다. 친밀도·신뢰·경쟁·갈등과 선택 이력이 저장됩니다.
- 25일 뒤 같은 인물이 다시 등장합니다. 성격·이전 선택·현재 관계에 따라 협력, 경쟁, 관계의 부담, 평행한 연습의 확률과 내용이 달라집니다.
- 친밀도가 높아도 경쟁이나 부담이 생길 수 있습니다. 관계와 협력 성과는 데뷔 평가에도 작은 영향을 줍니다.
- 오른쪽 인물 패널에서 인물별 관계와 최근 사건을 펼쳐 봅니다. 데뷔 시 그룹 멤버·포지션이 연결되고, 탈퇴·전향·은퇴 후에도 세계와 이력은 보존됩니다.
- 학생, 무계약, 무그룹, 미데뷔, 종료 상태의 사건 조건과 저장 참조 무결성을 검사합니다.

상세 데이터 모델과 조건·확률은 [세계 및 관계 문서](docs/world-state.md)를 참고하세요.

## 학생 시작 구조

이전 버전의 `entry`는 사실상 아이돌 준비생이었습니다. 이를 없애고 다음과 같이 구분했습니다.

| 상태 | 의미 |
| --- | --- |
| student | 13~18세에 시작하는 무소속 일반 학생 |
| auditioning | 오디션·캐스팅 심사 또는 계약 검토 중, 아직 무소속 |
| trainee | 소속사 계약을 마친 정규 연습생 |
| debut_candidate | 프로젝트 후보로 선발됐거나 최종 평가를 준비 중 |
| idol | 실제 데뷔해 그룹 활동 중 |
| solo | 그룹을 떠나 솔로 아이돌 활동 중 |
| actor / producer | 배우 / 제작·교육 분야로 전향 |
| ended | 이야기 또는 연예계 커리어 종료 |

신규 캐릭터에게 소속사, 그룹, 프로젝트, 경쟁 연습생, 데뷔 이력을 주지 않습니다. 아이돌 관심, SNS 활동, 학교 참여, 교류 정도도 캐릭터마다 다릅니다. 외모·가정환경·능력치 랜덤 생성과 성별에 따른 실력 차이가 없는 원칙은 유지합니다.

처음에는 학교·친구·가족·학업·취미·음악·춤·학교 행사·SNS 같은 일상이 쌓입니다. 학생에게 기존의 연습실·동료·소속사 평가·무대 활동 사건을 쓰지 않습니다. 평소 방침도 학업, 취미 탐색, 친구·학교생활, SNS 취미 기록, 컨디션 관리로 시작합니다.

초기 돈은 가족 재산이 아닌 **보유 현금**입니다. 가정환경에 따라 0~3 / 0~10 / 0~30만원에서 시작하며, 학생 월말에는 용돈과 개인 지출을 구분해 표시합니다. 산업 진입 이후의 경제는 기존의 단순화된 가상 수치 모델입니다.

## 산업 진입 경로

| 경로 | 발생 조건의 핵심 | 심사 기간 |
| --- | --- | --- |
| 공개 오디션 | 관심 또는 보컬 실력. 180일 뒤에는 관심과 무관하게 모집 공고 접촉 가능 | 14일 |
| 길거리 캐스팅 | 외모 | 10일 |
| SNS 발탁 | 공개 영상 게시 + 해당 영상의 게임 내 조회/노출 기록 | 18일 |
| 학교 공연 발탁 | 동아리 연습 후 실제 공개한 교내 공연·관객 기록 | 12일 |
| 거리 공연 발탁 | 음악 활동 연습 후 실제 거리 공연·관객 기록 | 12일 |
| 친구·지인 권유 | 교류 정도 | 16일 |
| 서바이벌 프로그램 | 15세 이상과 일정 수준의 관심 | 28일 |

각 경로는 서로 다른 발생 조건·추첨 가중치·합격 계산을 갖습니다. 플레이어에게 모든 진입 경로를 한꺼번에 고르게 하지 않고, 조건을 충족한 경로 중 하나의 제안이 찾아옵니다.

첫 기회 검토는 35~65일 후이며, 초기 한 달은 일반 학생의 일상을 보냅니다. 이후 보통 30~60일마다 새로운 기회를 검토합니다. 가능한 경로가 여러 개면 직전 경로의 연속 제안을 피합니다. 조건이 안 맞으면 시간을 흘려 다시 확인합니다. 선택만으로 합격은 보장되지 않습니다.

- 제안 거절 → 학생 생활 유지, 이후 다른 기회 가능
- 참여 → auditioning, 경로별 기간 뒤 심사 결과
- 불합격 → student 복귀, 다른 지원이나 재도전 가능
- 합격 → 아직 무소속, 계약 조건을 보고 다시 선택
- 계약 수락 → trainee 및 소속사 프로젝트 시작
- 계약 거절 → 무소속 student 복귀
- 서바이벌 선발·계약 수락 → 정규 trainee 대신 프로그램의 debut_candidate 과정. 최종 데뷔는 별도의 확률 평가가 필요

18개월 동안 학생 단계에 남으면 기다림을 계속할지 다른 일상의 이야기를 마무리할지 돌아보는 선택이 나옵니다. 강제로 연예계에 입사시키지는 않습니다.

## 시간·타임라인·결정

- 시작하면 자동 재생합니다. 최소 계산 단위는 1일입니다.
- ×1에서 현실 4분에 게임 365일, 1일 약 0.658초입니다. 실제 월 길이와 윤년을 따릅니다.
- ×1 / ×2 / ×4 / ×8, 수동 일시정지, 다음 결정까지 진행을 제공합니다.
- 배속과 관계없이 중간 날짜와 사건을 생략하지 않습니다. 같은 시드·같은 게임 날짜·같은 선택이면 같은 결과가 나옵니다.
- 중요한 결정은 중앙 팝업으로 나타나 시간을 멈춥니다. 선택 전에는 Escape나 배경 클릭으로 사라지지 않습니다.
- 선택하면 결과가 기록되고 즉시 재생됩니다. 결과 확인용 다음 버튼은 없습니다.
- 다음 결정까지는 최대 732일을 계산하며, 그 안에 결정이 없으면 기록을 남기고 멈춥니다.
- 커리어 소식은 **최신순**입니다. 과거 기록을 읽는 동안에는 보이던 소식을 기준으로 위치를 유지하고 상단에 새 소식 보기 버튼을 표시합니다. 이전 소식 더 보기는 아래에 있습니다.
- 기본 표시량은 최근 80개이며, 전체 기록은 저장합니다. 주요 소식 필터가 있습니다.
- 화면은 넓은 타임라인과 오른쪽 상태·방침·소속 패널로 구성합니다. 작은 화면에서는 한 열로 정리합니다.

## 산업 진입 이후

계약 → 새 그룹 프로젝트 발표 → 후보 선발 → 인원 조정 → 최종 평가 → 지연된 합격/탈락 결과 순서로 연결됩니다. 후보 선발 시 `debut_candidate` 상태를 구분하며, 누적 실력·월말 평가·경쟁 점수·훈련 기간·후보 이력·확률을 반영합니다. 탈락해도 실력은 남고 재도전이나 전향이 가능합니다.

데뷔한 뒤에는 작품 방향 선택 → 제작 → 발매 → 반응이 뒤늦게 돌아옵니다. 배우·제작자 전향, 그룹 탈퇴 후 솔로 활동, 아이돌 은퇴 후 연예 활동, 연예계 전체 은퇴를 구분합니다.

일반 사건, 결정, 예약 사건 모두 현재 상태 조건을 검사합니다. 소속사 없이 내부 평가가 나오거나, 데뷔 전에 팬덤이 생기거나, 그룹 없이 그룹 방송을 하는 일을 차단합니다. 배우의 팬 소식도 실제 작품 경력과 인기를 얻은 이후에만 나옵니다. 사건별 상세 감사표는 [사건 조건 문서](docs/event-conditions.md)에 있습니다.

## 저장과 종료

약 2초마다 자동 저장하고, 중요한 결정 발생·선택·시간 제어·방침 변경·페이지 이탈에도 저장합니다. 날짜, 시드 난수, 예약 사건, 대기 결정, 방침과 소속 상태를 모두 저장합니다. 탭이 비활성화되거나 창을 닫은 실제 시간은 게임에 반영하지 않습니다.

세계·관계 버전은 `idol-career-v04` 키와 스키마 4를 사용합니다. 이전 `v03`·`v02`·`v01` 저장은 삭제하거나 덮어쓰지 않고, 구조 변경과 새 게임 필요 안내를 표시합니다. 손상된 ID 참조나 관계 이력도 안전하게 거부합니다. 저장 초기화를 명시적으로 선택하면 구버전 키도 지웁니다. 기기나 브라우저 간 동기화는 없습니다.

체력/멘탈이 크게 떨어지면 회복 또는 은퇴를 결정하며, 준비 단계에 오래 남거나 데뷔 실패가 누적되면 전향 기회가 나옵니다. 45세에는 커리어를 정리합니다. 끝나면 주요 경력·최고 인기·자산·업적·전향과 은퇴 과정·에필로그와 전체 기록을 볼 수 있습니다. 학생은 연예계 은퇴가 아닌 이야기 마무리를 선택할 수 있습니다.

## 남은 점검 과제

- 경로별 만남 빈도·합격 확률·학생 기간의 체감은 초기 수치입니다. 첫 한두 달이 충분히 일상처럼 느껴지는지, 반대로 진입이 답답하지 않은지 플레이로 조정해야 합니다.
- 학교는 참여·관심·교류 중심의 간단한 모델입니다. 학년·진학·교우 관계를 세밀하게 계산하지 않습니다.
- 학생의 용돈·현금은 구분했지만 산업 진입 후 비용·정산은 단순 모델입니다. 가족 지원, 소속사 투자와 개인 부채의 상세 분리는 후속 과제입니다.
- 기존 30개 일반 소식과 16개 결정 기반에 7개 경로별 제안이 추가됩니다. 긴 플레이에서는 문구가 반복됩니다.
- 전체 NPC의 독립적인 인생 시뮬레이션, 정교한 그룹 케미스트리, 정교한 음원 경제, AI 스토리, 오프라인 진행, 자동 결정, 여러 저장 슬롯과 클라우드 동기화는 없습니다.
- 실제 iOS/Android 기기 검증은 별도 과제입니다. 이번 수정의 주 대상은 데스크톱 웹입니다.
